# Full-stack deployment

This page is intentionally only a canonical redirect. There must be one
source of truth for the fresh five-service deployment:

**[Read `docs/all-in-one.md`](all-in-one.md).**

The final onboarding state is **Ready** (with **Repair** for a later
completed-installation failure). The safe default is
`BIND_ADDRESS=127.0.0.1`; the canonical guide also documents loopback binds,
SSH forwarding, Jellyfin authentication,
draft-versus-Run-configuration behavior, ownership, backup/restore, key
rotation, NVIDIA setup, recovery, and troubleshooting.
